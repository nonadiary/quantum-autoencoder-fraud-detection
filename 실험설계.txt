## 연구 설계 제안서: 양자 및 비양자 사기 탐지 시스템(FDS) 비교 분석

### **1. 서론**

본 문서는 사기 탐지 시스템(FDS) 분야에서 다양한 양자 컴퓨팅 기법과 전통적인 비양자(고전) 기법의 성능을 공정하고 유의미하게 비교하기 위한 연구 설계안을 제안합니다. 연구의 목표는 각 기법의 효율성, 자원 요구사항, 훈련 가능성을 객관적으로 평가할 수 있는 엄격한 실험적 프레임워크를 구축하는 것입니다. 이를 위해, 모든 실험에서 일관되게 유지해야 할 **통제 변인(Controlled Variables)**과 각 방법론의 고유한 특성을 평가하기 위해 의도적으로 변경해야 할 **독립 변인(Independent Variables)**을 명확히 구분하여 설계합니다.

---

### **2. 통제 변인 (Controlled Variables)**

실험 결과의 신뢰성과 재현성을 보장하고, 성능 차이가 오직 알고리즘 자체의 우수성에서 비롯되었음을 입증하기 위해 다음 변인들은 모든 실험에서 **반드시 동일하게 유지**되어야 합니다.

| 변인 그룹 | 통제 변인 | 통제 이유 및 세부 사항 |
| :--- | :--- | :--- |
| **데이터 관련** | **데이터셋** | 모든 모델은 동일한 데이터셋으로 훈련 및 평가되어야 합니다. 특히 신용카드 거래 데이터와 같이 실제 사기 탐지 환경을 반영하는 **고도로 불균형한(imbalanced) 데이터셋**을 사용해야 합니다.[1] |
| | **데이터 분할** | 훈련(Training), 검증(Validation), 테스트(Test) 데이터셋의 분할 비율과 구성원은 모든 실험에서 완전히 동일해야 합니다. 이는 모델 일반화 성능을 공정하게 비교하기 위함입니다. |
| | **데이터 전처리** | 모든 모델에 입력되는 데이터는 동일한 전처리 과정을 거쳐야 합니다. 여기에는 수치형 데이터의 정규화(Normalization) 또는 표준화(Standardization), 범주형 데이터의 인코딩 방식 등이 포함됩니다. |
| **모델 훈련 관련** | **고전 최적화 환경** | 양자 모델의 변분 파라미터 최적화나 고전 모델의 훈련에 사용되는 고전 컴퓨팅 환경(CPU, GPU, RAM 등)은 동일해야 합니다. 이는 훈련 시간과 같은 계산 비용을 공정하게 비교하기 위함입니다. |
| | **에포크 및 배치 크기** | 최대 훈련 에포크(Epoch) 수와 배치 크기(Batch Size)는 모든 모델에 동일하게 설정하여, 각 모델이 동일한 양의 데이터 노출과 업데이트 기회를 갖도록 보장합니다. |
| **평가 관련** | **평가 지표** | 모든 모델의 성능은 동일한 평가 지표 세트를 사용하여 측정되어야 합니다. 불균형 데이터의 특성을 고려하여, 단순 정확도(Accuracy)가 아닌 **AUC (Area Under the ROC Curve), G-Mean, 정밀도(Precision), 재현율(Recall), F1-Score** 등을 핵심 지표로 사용해야 합니다.[2] |
| | **최종 테스트** | 모든 모델의 최종 성능 평가는 이전에 한 번도 사용되지 않은(unseen) 동일한 테스트 데이터셋에 대해 수행되어야 합니다. |

---

### **3. 독립 변인 (Independent Variables)**

본 연구의 핵심적인 비교 대상인 방법론들입니다. 각 방법론은 고유의 아키텍처와 작동 원리를 가지며, 이들의 차이가 성능에 미치는 영향을 분석하는 것이 주된 목표입니다.

| 변인 그룹 | 독립 변인 (비교 대상) | 설명 |
| :--- | :--- | :--- |
| **양자 기법 (Quantum Methods)** | **QAE - SWAP 테스트 기반** | 'QAE Angle'과 같이, 쓰레기 상태(trash state)의 충실도를 측정하기 위해 보조 큐비트(ancilla qubit)와 제어-SWAP(CSWAP) 게이트를 사용하는 전통적인 양자 오토인코더 방식입니다.[3] |
| | **QAE - DIFE 기반** | 파괴적 간섭 충실도 추정(Destructive Interference Fidelity Estimation)을 활용하여 보조 큐비트 없이 쓰레기 상태의 충실도를 측정하는 자원 효율적인 양자 오토인코더 방식입니다.[4, 5] |
| | **기타 양자 분류기** | (선택 사항) 변분 양자 분류기(Variational Quantum Classifier, VQC)나 양자 서포트 벡터 머신(Quantum Support Vector Machine, QSVM)과 같은 다른 양자 머신러닝 모델을 포함하여 비교의 폭을 넓힐 수 있습니다. |
| **비양자 기법 (Non-Quantum Methods)** | **고전 오토인코더** | 양자 오토인코더의 직접적인 고전적 대응 모델로서, 이상 탐지(anomaly detection)를 위한 벤치마크 역할을 합니다.[6] |
| | **앙상블 기반 분류기** | 불균형 데이터 처리에 강력한 성능을 보이는 XGBoost, LightGBM, Random Forest와 같은 최신 고전 머신러닝 모델을 포함하여 현실적인 성능 기준을 제시합니다.[6] |
| | **기본 선형 모델** | 로지스틱 회귀(Logistic Regression)와 같은 간단한 모델을 포함하여, 복잡한 모델들이 제공하는 성능 향상의 정도를 가늠하는 기본선(baseline)을 설정합니다. |

---

### **4. 종속 변인 (Dependent Variables) - 평가 지표 설계**

독립 변인(각 방법론)의 성능을 정량적으로 측정하고 비교하기 위해 다음과 같은 종속 변인들을 설정하고 추적해야 합니다.

| 평가 차원 | 종속 변인 (측정 지표) | 설명 및 측정 목적 |
| :--- | :--- | :--- |
| **모델 성능 (Effectiveness)** | **AUC, G-Mean, F1-Score** | 모델이 사기 거래(소수 클래스)를 얼마나 정확하게 탐지하는지를 종합적으로 평가합니다. 불균형 데이터셋에서의 분류 성능을 나타내는 핵심 지표입니다.[1] |
| | **재구성 오류** | 오토인코더 기반 모델(양자 및 고전)의 경우, 정상 거래와 사기 거래의 재구성 오류 분포를 분석하여 이상 탐지 성능을 직접적으로 평가합니다.[6] |
| **자원 효율성 (Resource Efficiency)** | **필요 큐비트 수** | 각 양자 모델을 구현하는 데 필요한 총 큐비트 수(데이터 큐비트 + 보조 큐비트)를 측정합니다. 이는 NISQ 장치에서의 확장성을 평가하는 중요한 척도입니다.[7] |
| | **회로 깊이 및 게이트 수** | 양자 회로의 깊이와 2-큐비트 게이트(예: CNOT)의 수를 측정합니다. 이는 회로의 복잡성과 잡음에 대한 민감도를 나타냅니다. |
| | **훈련 시간** | 각 모델이 수렴에 도달하기까지 소요되는 총 벽시계 시간(wall-clock time)을 측정하여 계산 효율성을 비교합니다. |
| **훈련 가능성 (Trainability)** | **기울기 분산** | 양자 모델의 훈련 과정에서 비용 함수의 기울기 분산을 측정합니다. 이는 **황무지 평원(barren plateau) 현상**의 존재 여부와 심각성을 정량적으로 진단하는 지표가 됩니다.[8, 9] |
| | **수렴 속도** | 각 모델이 최적의 성능에 도달하기까지 필요한 훈련 반복 횟수(iteration) 또는 에포크 수를 측정합니다. |
| | **잡음 하 성능 저하** | (시뮬레이션 환경) 실제 양자 하드웨어의 잡음을 모사하는 잡음 모델을 적용했을 때, 각 양자 모델의 성능이 얼마나 저하되는지를 평가하여 잡음에 대한 강건성(robustness)을 비교합니다. |

이와 같이 통제된 실험 환경을 설계함으로써, 각 FDS 기법의 장단점을 명확히 규명하고, 특정 조건 하에서 어떤 방법론이 가장 우수한지를 객관적으로 판단할 수 있는 신뢰도 높은 연구 결과를 도출할 수 있을 것입니다.

대부분의 양자 및 비양자 머신러닝 모델은 내재된 확률적(stochastic) 요소로 인해 실행할 때마다 결과가 조금씩 변동될 수 있습니다. 따라서 여러 번의 독립적인 반복 실험을 수행한 후, 그 결과의 **평균과 표준편차를 함께 측정하고 보고하는 것이 필수적**입니다.

### 1. 결과 변동의 원인 (Sources of Randomness)

각 모델에서 결과가 변동될 수 있는 주요 원인은 다음과 같습니다.

#### **양자 기법 (QAE, DIFE 등)**

1.  **매개변수 초기화 (Parameter Initialization):** 변분 양자 회로(Variational Quantum Circuit)의 학습 가능한 매개변수(예: 회전 게이트의 각도)는 훈련 시작 시 무작위 값으로 초기화됩니다. 이 초기값이 어디에 설정되느냐에 따라 최적화 알고리즘이 탐색하는 경로가 달라지며, 최종적으로 수렴하는 지점(지역 최적해, local minimum)이 달라져 최종 성능에 영향을 미칩니다. '항등 블록 초기화'와 같은 고급 기법조차도 일부 매개변수는 무작위로 선택하는 과정을 포함하므로, 여전히 무작위성의 원인이 됩니다.[1]
2.  **양자 측정의 확률성 (Shot Noise):** 양자 컴퓨터의 측정 결과는 본질적으로 확률적입니다. 유한한 횟수의 측정(샷, shots)을 통해 확률 분포를 추정하므로, 실행할 때마다 통계적 오차(샷 잡음)가 발생하여 비용 함수 값과 기울기가 미세하게 변동합니다.
3.  **확률론적 최적화기 (Stochastic Optimizers):** SPSA와 같은 일부 최적화기는 매 반복마다 무작위 방향으로 매개변수를 흔들어 기울기를 근사합니다.[2] 이 무작위 방향 벡터는 실행 시마다 달라지므로, 동일한 초기점에서 시작하더라도 훈련 경로는 매번 달라집니다.

#### **비양자 기법 (고전 모델)**

1.  **가중치 초기화 (Weight Initialization):** 고전 오토인코더와 같은 신경망 모델은 훈련 시작 시 연결 가중치를 무작위 값으로 초기화합니다. 이는 양자 모델의 매개변수 초기화와 동일한 효과를 낳습니다.
2.  **확률적 경사 하강법 (Stochastic Gradient Descent, SGD):** 대부분의 딥러닝 모델은 훈련 데이터의 일부(미니배치, mini-batch)를 무작위로 샘플링하여 매개변수를 업데이트합니다. 이 미니배치의 구성이 훈련 시마다 달라져 결과에 변동을 일으킵니다.
3.  **알고리즘 고유의 무작위성:** 랜덤 포레스트(Random Forest)와 같은 앙상블 모델은 부트스트랩 샘플링(데이터 무작위 복원 추출)이나 무작위 특징 선택과 같이 알고리즘 자체에 무작위성을 적극적으로 활용합니다.

### 2. 반복 측정 및 평균화의 필요성

이러한 무작위성으로 인한 결과의 변동성을 통제하고 신뢰할 수 있는 결론을 도출하기 위해, **반복 실험 후 평균을 측정하는 것은 과학적 연구의 표준적인 절차**입니다.

*   **신뢰성 확보:** 단 한 번의 "운 좋은" 또는 "운 나쁜" 실행 결과에 기반하여 모델의 성능을 평가하는 것은 매우 위험합니다. 여러 번의 실행 결과를 평균하면 특정 실행에 의한 편향을 줄이고, 모델의 **기대 성능(expected performance)**에 대한 더 안정적이고 신뢰할 수 있는 추정치를 얻을 수 있습니다.
*   **통계적 유의성 검증:** 반복 실험을 통해 결과의 평균뿐만 아니라 **표준편차(standard deviation)**나 **표준오차(standard error)**도 계산할 수 있습니다. 이는 결과의 변동성을 정량화하여 "모델 A가 모델 B보다 0.01 AUC만큼 우수하다"는 주장이 통계적으로 유의미한 차이인지, 아니면 단순히 무작위 변동에 의한 것인지 판단하는 근거가 됩니다. 예를 들어, 결과를 `평균 ± 표준편차` 형태로 보고하면 모델 성능의 안정성까지 함께 보여줄 수 있습니다.
*   **공정한 비교:** 모든 모델에 대해 동일한 횟수의 반복 실험을 수행하고 그 통계치를 비교함으로써, 무작위성의 영향을 공정하게 통제하고 오직 알고리즘 자체의 성능 차이를 비교할 수 있습니다.

### 3. 연구 설계를 위한 구체적인 제안

따라서, 제안된 연구 설계에 다음 절차를 추가하는 것이 바람직합니다.

1.  **난수 시드(Random Seed) 관리:** 각 반복 실험이 독립적으로 이루어지도록, 매 실행마다 다른 난수 시드를 설정합니다.
2.  **반복 횟수 설정:** 계산 비용을 고려하여 각 모델에 대해 최소 5~10회 이상의 독립적인 훈련 및 평가를 반복합니다.
3.  **결과 기록:** 각 반복에서 얻은 모든 평가 지표(AUC, G-Mean, F1-Score 등)를 기록합니다.
4.  **최종 결과 보고:** 최종적으로 각 모델의 성능을 보고할 때, 단일 값이 아닌 **평균(mean)과 표준편차(standard deviation)**를 함께 제시합니다.

이러한 절차를 통해 연구 결과의 신뢰도를 크게 높이고, 각 FDS 기법의 성능에 대한 더욱 강력하고 설득력 있는 결론을 내릴 수 있을 것입니다.
